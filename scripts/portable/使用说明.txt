KeyCat 1.0.1 · 桌面键鼠 / 手柄显示
====================================

一、怎么用
---------
1. 整个文件夹解压到任意位置（比如 D:\KeyCat），双击 KeyCat.exe 就能直接跑（免安装）。
2. 想要开始菜单 / 桌面快捷方式和「应用和功能」里的卸载项，双击 install.cmd 一次即可：
   它会复制到 %LOCALAPPDATA%\Programs\KeyCat，建好快捷方式并启动。
3. 卸载：双击安装目录里的 uninstall.cmd，或者系统「设置 → 应用和功能」里卸载 KeyCat。

注意：不要放在被安全软件 / 云同步 / 沙箱接管的目录里运行，否则 Chromium 的 GPU 子进程
可能被拦住，表现为双击无反应。装到 %LOCALAPPDATA%\Programs\KeyCat 或 D:\KeyCat 都没问题。

二、启动之后
-----------
- 桌面上会直接出现预设（默认是「鼠标箭头 + WASD 极简」，在屏幕下方中间）。
- 右下角托盘有 KeyCat 图标（可能收在 ^ 里），双击它打开设置。
- 启动日志：%APPDATA%\KeyCat\startup.log，出问题时先看这里。
- 配置文件：%APPDATA%\KeyCat\config.json

三、快捷键
---------
Ctrl + Alt + E   进入 / 退出编辑模式（拖动、滚轮缩放、Del 删除、Esc 退出）
Ctrl + Alt + H   显示 / 隐藏覆盖层
Ctrl + Alt + S   打开设置窗口

四、设置里能做什么
-----------------
- 预设库：33 个内置预设，点 ＋ 放到屏幕上，同一个预设可以放多个
- 屏幕布局：逐项调位置 / 大小 / 透明度 / 层叠顺序，一键自动排列
- 设置：鼠标穿透、始终置顶、不透明度、刷新率、鼠标灵敏度 / 死区、开机自启、演示模式

五、已知限制
-----------
- 手柄需要显示层窗口获得焦点（Chromium Gamepad API 的限制）
- 独占全屏游戏可能盖住覆盖层，建议游戏用无边框窗口
- 目前只铺主显示器
