KeyCat v1.0.0

仿 BongoCat 的桌面键鼠 / 手柄输入显示，内置 input-overlay 5.0.5 全部预设，并支持在屏幕上同时摆放多个预设。

  • 预设格式：兼容 univrsal/input-overlay 5.0.x 的 layout JSON + PNG 图集（元素类型 0~9）。
  • 全局监听：由 uiohook-napi（libuiohook）提供低层键鼠钩子。
  • 手柄：浏览器 Gamepad API，需要手柄与显示层窗口获得焦点。
  • 素材版权：预设与图集来自 input-overlay 社区，遵循其原始授权；本程序仅做渲染与交互。
  • 灵感来源：ayangweb/BongoCat。
